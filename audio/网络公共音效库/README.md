## 归类说明

- 主题明确的整包直接归入对应分类（如 GUI 界面音效→02，魔法咒语→04）；
- 混合包按**文件名关键词**细分到各分类（coin→06、button→02、break→05 等）；
- 文件名保留原始命名，便于回溯源包；同一包分散在多个分类时，每处目录内都有相同的 SOURCE.txt。

## 许可与使用说明

- 全部为 **CC0 1.0 公共领域**：可商用、可修改、可再分发，无需署名（保留 SOURCE.txt 是良好习惯）。
- 格式以 WAV/OGG/MP3 为主，可直接导入 Cocos Creator / Unity / Godot / Web 等引擎。
- 来源页面：OpenGameArt 内容页与 GitHub 仓库地址见上表；下载日期 2026-11-06。
- 注：本库剔除过一批质量较差的包，仅保留筛选后的内容。

## 备注
